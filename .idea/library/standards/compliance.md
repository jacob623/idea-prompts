# Compliance Controls

## Cloud Security Alliance (CSA) Cloud Controls Matrix v4
All cloud-native infrastructure, platforms, and workloads must adhere to all
applicable CSA CCM v4 Controls.

## CIS Benchmarks
All infrastructure, platforms, and workloads must be hardened to the applicable
CIS Benchmark for each technology in use.

## Availability and Resilience
All infrastructure, platforms, and workloads must be highly available and
resilient, with documented RPO/RTO targets and tested recovery procedures.

## Infrastructure as Code and Desired State Configuration
All infrastructure, platforms, and workloads must support Infrastructure as Code
(IaC) and Desired State Configuration (DSC) management. Manual provisioning is
not permitted in non-development environments.
